# Портфолио Дениса Волошина

Сайт: https://denisvoloshin.ru. GitHub Pages публикует ветку `main`.

## Обновление

Данные проектов, фотографии и SEO хранятся в `src/content.json`, общий HTML — в `src/template.html`. После изменения выполните из корня репозитория:

```sh
node scripts/build.cjs
```

В коммит должны попасть исходники и сгенерированные `index.html`, `vnevremeni/index.html`, `vglubine/index.html`, `assets/content.js`. Сборка не требует сторонних пакетов. Общие стили и поведение находятся в `assets/site.css` и `assets/site.js`.

## Фотографии

- `url` — существующий файл Tilda CDN для слайд-шоу и полноразмерного просмотра.
- `id` — постоянный идентификатор кадра. Не изменяйте его при перестановке фотографий или замене URL: опубликованные ссылки используют этот ID.
- `width` и `height` — исходные пропорции фотографии.
- `thumb` — путь без суффикса к двум JPEG в `assets/thumbs`: `-400.jpg` и `-800.jpg`. Они должны сохранять пропорции, без дополнительной обрезки. Текущее качество JPEG — 88.

Новые кадры получают новый уникальный ID. Начальные ID получены из первых 12 символов SHA-256 исходного URL с префиксом `p-`. При добавлении фотографии обновляйте также список изображений в `sitemap.xml`.

## Ссылки и «Поделиться»

Пример: `/vglubine/?photo=p-d672b884660d#mini`. Адрес открывает существующий поп-ап, а стрелки обновляют кадр без перезагрузки. Закрытие возвращает к миниатюрам. Кнопка «Поделиться» использует системное меню, если браузер его поддерживает; иначе копирует ссылку. При запрете буфера обмена появляется окно с адресом для ручного копирования. Отмена системного меню ничего не копирует.

Canonical и карточка предпросмотра остаются общими для проекта: отдельные URL кадров предназначены для точного открытия фотографии, а не для создания дубликатов страниц в поиске.

Статический HTML содержит ссылки, описания и миниатюры до запуска JavaScript. При обычной работе используется прежний интерфейс; без JavaScript доступна запасная статическая галерея.
